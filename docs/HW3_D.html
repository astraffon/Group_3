3) What is Git and what is GitHub?

Git is a local version control software that is used to track changes within a code. GitHub is an online hosting service for Git-based projects that allows you to collaborate with others.

4) What are the two main differences between a tibble and a data.frame?

A tibble is an optimized version of a data frame that prints cleaner data. It is the main object of the tidyverse packaging. When printed, it only shows the first 10 rows of the data set and the data type of each column. When extracting a single column, it will return another tibble.

A data.frame is the standard Base R object. When printed, it shows the entire data set and does not show the data type. When extracting a single column, it will return a vector.
