2. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

Long format data has one observation per row, with different variables or measurements stored in separate columns. Wide format data has multiple measurements for the same observation stored across different columns, so the same observation may have values in several columns. Long format data is preferred for statistical analysis.
