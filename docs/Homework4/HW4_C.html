2. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

Long format data may, for example, have repeated values from the same subject but at different points in time. It is valuable for finding overall averages and other descriptives, regardless of when measurements were taken. Wide data has each subject only listed once, and their repeated measures are list out on that row of the table, allowing for trend analysis.
