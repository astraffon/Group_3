2. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

Long format data basically has one observation per row, while wide format data can have multiple observations across different columns in the same row. For statistical analysis working with long format is generally easier for when plotting, summarizing, and modeling data.
