Task 1: Conceptual Questions

1) If your working directory is myfolder/homework/, what relative path would you specify to get the file located at myfolder/MyData.csv?

../MyData.csv Because .. moves up one directory to myfolder/, where MyData.csv is located.

2) What are the major benefits of using R projects?

As noted in Week 1, R projects make it easier to work on a project by organizing it in its own working directory, workspace, history, and files. The use of relative file paths makes it easier to share and collaborate with others, while also tracking changes through version control software.

3) What is Git and what is GitHub?

Git is a version control system to track changes in text files, such as code. GitHub is an online repository of these text files and backups, allowing for easy working between multiple computers and across teams using gib-based projects. It can also help track and resolve version control conflicts, such as when two team members are editing the same files.

4) What are the two main differences between a tibble and a data.frame?

A tibble is designed to be a little more user-friendly because it prints a cleaner summary of the data and is more consistent when subsetting columns and rows. Also, similar to other applications (Stata, SAS, SPSS), modifying a tibble returns a tibble, whereas modifying a data frame usually returns a vector (single variable) that has changed while leaving the rest of the data set behind.

8) Write a basic function (call it getIQR) that takes in a vector of numbers and returns the interquartile range (75th percentile - 25th percentile). You can use the quantile function. Remove the name on the returned vector (i.e. make sure the returned item doesn’t have a name like 75% or something like that). Allow your function to pass unnamed arguments to the quantile function.

getIQR <- function(x, ...) {
  q75 <- quantile(x, 0.75, ...)
  q25 <- quantile(x, 0.25, ...)
  setNames((q75 - q25), "IQR")
