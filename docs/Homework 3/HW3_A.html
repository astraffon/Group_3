2) What are the major benefits of using R projects?

As noted in Week 1, R projects make it easier to work on a project by organizing it in its own working directory, workspace, history, and files. The use of relative file paths makes it easier to share and collaborate with others, while also tracking changes through version control software.

3) What is Git and what is GitHub?

Git is the version control software that we use to track changes in R Projects, whereas GitHub is an online hosting service that allows for collaborative work on Git-based projects.

4) What are the two main differences between a tibble and a data.frame?

  1. A tibble is a special version of a data frame and is the main tabular object used in the tidyverse, whereas a data.frame is the standard base R structure for tabular data.
  2. A tibble is designed to be a little more user-friendly because it prints a cleaner summary of the data and is more consistent when subsetting columns and rows.

Task 4: Writing a Function

8) Write a basic function (call it getIQR) that takes in a vector of numbers and returns the interquartile range (75th percentile - 25th percentile). You can use the quantile function. Remove the name on the returned vector (i.e. make sure the returned item doesn’t have a name like 75% or something like that). Allow your function to pass unnamed arguments to the quantile function.

getIQR <- function(x, ...) {
  q <- quantile(x, probs = c(0.25, 0.75), ...)
  iqr <- q[2] - q[1]
  return(unname(iqr))
}

10) Write another function (call it getCoefVar) that returns the sample coefficient of variation, defined as the sample standard deviation divided by the absolute value of the sample mean. Allow the function to pass unnamed arguments to sd and mean.

getCoefVar <- function(x, ...) {
  s <- sd(x, ...)
  xbar <- mean(x, ...)
  cv <- s / abs(xbar)
  return(cv)
}
