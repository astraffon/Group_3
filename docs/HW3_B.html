Task 1: Conceptual Questions

1) If your working directory is myfolder/homework/, what relative path would you specify to get the file located at myfolder/MyData.csv?

Since the working directory is myfolder/homework/, .. moves up one directory to myfolder/, where MyData.csv is located.

2) What are the major benefits of using R projects?

R Projects keep all files for a project together, automatically establish the project directory, make relative file paths easier to use, and help make analyses organized, portable, and reproducible.

3) What is Git and what is GitHub?

Git is a version control system that tracks changes to files and allows you to return to earlier versions or collaborate on code. GitHub is an online platform that hosts Git repositories, making it easier to store, share, and collaborate on projects.

4) What are the two main differences between a tibble and a data.frame?

A tibble is a newer version of a data frame in R. One difference is how they print: tibbles only show the rows and columns that fit on the screen, while data frames may print the whole dataset. Another difference is when you select a single column. A tibble usually keeps it as a tibble, while a data frame may turn it into a vector.

Task 4: Writing a Function

8) Write a basic function (call it getIQR) that takes in a vector of numbers and returns the interquartile range (75th percentile - 25th percentile). You can use the quantile function. Remove the name on the returned vector (i.e. make sure the returned item doesn’t have a name like 75% or something like that). Allow your function to pass unnamed arguments to the quantile function.

getIQR <- function(x, ...) {
  q75 <- quantile(x, 0.75, ...)
  q25 <- quantile(x, 0.25, ...)
  
  unname(q75 - q25)
}

10) Write another function (call it getCoefVar) that returns the sample coefficient of variation, defined as the sample standard deviation divided by the absolute value of the sample mean. Allow the function to pass unnamed arguments to sd and mean.

getCoefVar <- function(x, ...) {
  sd(x, ...) / abs(mean(x, ...))
}
