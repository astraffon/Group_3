We have 8,760 observations across 14 variables (columns). Of these 10 are numeric and 4 are character variables. Three of the character variables are categorical (Seasons, Holiday, Functioning Day) while the Date variable needs to be converted to the proper date format.

Each observation represents one hour of bike rental activity, rather than an individual rental. The Hour variable identifies the hour of the day (0–23), while Rented Bike Count represents the number of bikes rented during that hour. The dataset covers 365 days, with 24 hourly observations per day, so there are a total of 8,760 observations.

7) Converting to daily dataset

To simplify the remaining analysis we aggregate hourly observations into daily totals.

# Aggregate hourly observations into daily observations
bike_daily <- bike_data |>
  group_by(date, seasons, holiday) |> # group_by() organizes observations into desired groups
  summarise(
    # Calculate daily totals
    bike_count = sum(bike_count),
    rainfall = sum(rainfall),
    snowfall = sum(snowfall), 

    # Calculate daily averages for weather variables
    temp = mean(temp),
    humidity = mean(humidity),
    wind_speed = mean(wind_speed),
    visibility = mean(visibility),
    dew_point_temp = mean(dew_point_temp),
    solar_radiation = mean(solar_radiation),

    # Remove grouping after summarizing
    .groups = "drop"
  )

V. Fitting MLR Models

In this section we will fit three different MLR models of the general form:

\[ \hat{Y}_i = \hat{\beta}_0 + \sum_{j=1}^{p} \hat{\beta}_j X_{ij} \]

Where:

  • \(\hat{Y}_i\) = predicted daily bike rentals for observation \(i\).
  • \(\hat{\beta}_0\) = estimated intercept.
  • \(\hat{\beta}_j\) = estimated regression coefficient for predictor \(j\).
  • \(X_{ij}\) = value of predictor \(j\) for observation \(i\).
  • \(p\) = number of predictor terms in the model.

But first we will create a new categorical variable and standardize the datasets.

1) Creating a new categorical variable

To assess whether daily bike rentals differ between weekdays and weekends, we introduce a new categorical variable called day_type with the wday() function. We converted this variable into a factor with two levels, Weekday and Weekend, in both the training and test datasets.

# Create a weekday/weekend factor in the training dataset
bike_train <- bike_train |>

      if_else(wday(date, week_start = 1) >= 6, "Weekend", "Weekday"),

2) Creating standardized versions of numeric variables

Why and how do we standardize the numerical predictors? We do this to put them on a common scale (mean of 0 and standard deviation of 1), making their regression coefficients easier to compare. We do this by using the z-score for each numeric variable.

\[ z_i = \frac{x_i - \bar{x}}{s} \] An important requirement is that both the training and test datasets must be standardized using the means and standard deviations calculated from the training set only, as this avoids data leakage and ensures the model is evaluated on previously unseen data.

- Step 4: Finding the test RMSE for each model

Now we’ll calculate the test-set RMSE (Root Mean Squared Error) for each of the three models using the following formula:

\[ RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(Y_i-\hat{Y}_i)^2} \]

Where \(Y_i\) represents actual daily bike rentals and \(\hat{Y}_i\) represents predicted rentals.

We use the predict() function to estimate the bike rentals for each model. The model with the lowest test-set RMSE will become the preferred model.

+ Generate predictions using the test dataset
# Generate predicted daily bike rentals for each model
# Use the test dataset, which was not used to fit the models
pred_1 <- predict(model_1, newdata = bike_test)
pred_2 <- predict(model_2, newdata = bike_test)
pred_3 <- predict(model_3, newdata = bike_test)
+ Calculate RMSE for each model
# Calculate the RMSE for each model using formula
rmse_1 <- sqrt(mean((bike_test$bike_count - pred_1)^2))
rmse_2 <- sqrt(mean((bike_test$bike_count - pred_2)^2))
rmse_3 <- sqrt(mean((bike_test$bike_count - pred_3)^2))
+ Compare the results
# Create a data frame to compare test-set RMSE values
rmse_results <- data.frame(
  Model = c("Model 1", "Model 2", "Model 3"),
  RMSE = c(rmse_1, rmse_2, rmse_3)
)

# Display results, ordered from lowest to highest RMSE
rmse_results |>
  arrange(RMSE)
    Model     RMSE
1 Model 3 3048.160
2 Model 2 3080.801
3 Model 1 4046.254

After calculating the test-set RMSE for each of our three models, we find that Model 3 has the lowest RMSE (3,048), followed closely by Model 2 (3,081). Model 1 has the highest RMSE (4,046). Adding interaction terms significantly improved predictive accuracy, while the additional quadratic terms provided a smaller improvement. Based on these results, we select Model 3 as our preferred model.
